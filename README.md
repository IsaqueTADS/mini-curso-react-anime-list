# React com Vite na Prática: Lista de Animes

Este repositório contém o esqueleto inicial do projeto prático do minicurso **React com Vite na Prática: Construindo uma Aplicação de Listagem e Detalhes de Animes**, realizado no IFNMG. Os alunos poderão baixar este projeto e desenvolvê-lo ao longo das aulas, acompanhando as apostilas.

Durante o minicurso, o projeto será construído passo a passo para praticar os fundamentos do React com Vite e criar uma aplicação de listagem e detalhes de animes.

## Minicurso

- **Apresentador:** Isaque Rodrigues Alves
- **Marca:** isaqueTADS
- **Instituição:** IFNMG — Instituto Federal do Norte de Minas Gerais
- **Datas:** 28 e 29 de setembro de 2026
- **Carga horária:** 2 horas, divididas em duas aulas de aproximadamente 1 hora
- **Público:** pessoas iniciantes em React

## Executar o projeto

Requisitos: Node.js e npm instalados.

```bash
npm install
npm run dev
```

O Vite exibirá no terminal o endereço local para abrir a aplicação.

## Apostilas

As apostilas que orientam o desenvolvimento estão na pasta [`lessons/aula-1`](lessons/aula-1/).

## Tecnologias

React, TypeScript e Vite.
